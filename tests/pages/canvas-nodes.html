How to use this template

This workflow uses a turnaround sheet as input. You can create one with the character sheet template first, then load it here.

  • Set the image size before you run the workflow.
  • Lower the steps if your GPU runs out of memory.

The last group saves every view into the output folder, so you can compare them side by side.

If the colors look washed out, raise the guidance a little and run it again.
