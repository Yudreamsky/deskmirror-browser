# 桌面魔镜浏览器版 · 更新记录

## 0.7.0（2026-10-10）
- 标签左头加了抓手：按住它把魔镜拖到页面左右边缘，魔镜缩成球吸在边上、藏进一半，停止翻译；从边上把球拖出来，球平滑地变成虚线框跟着鼠标走，同时开始翻译，松手就落定成魔镜。一次拖动里来回变也行。
- 新选项“所有网页默认显示魔镜气泡”（设置页“外观”里）：打开后每个网页一打开，边上就有一个藏起一半的魔镜气泡，点一下打开魔镜，关掉魔镜又缩回气泡；输入框连按三次空格也在所有网页上都能用。气泡不复制网页、不翻译，点开才开始，每个网页只多花十毫秒左右。打开时 Chrome 会请求访问所有网站的权限。
- 网页上只有气泡时，点工具栏图标或按 Alt+Shift+M 会把它弹开成魔镜。
- 自己会动的卡片（轮播图、跑马灯，比如 labs.google/playground 的横向卡片）在镜子里和真网页对齐，不再错开：复制品里的动画、过渡直接跟着真网页的走。刚打开魔镜时影子 DOM 里的改动也不再漏掉。
- 关掉魔镜时，还没译完的请求马上停下，不再继续消耗 token。
- 打印网页时不印镜框和气泡。

## 0.6.0（2026-10-08）
- 输入框翻译：在网页的输入框里连按三次空格（每两下之间不超过 0.5 秒），把你打的母语翻译成设置里“输入框翻译成”的语言，直接替换，按 Ctrl+Z 撤回。单行框、多行框、富文本编辑框都能用；行首缩进的空格、输入法选字的空格不会误触；翻译时又打了字就不替换。在打开过魔镜的网页上才能用，关掉魔镜也行。

## 0.5.3（2026-10-08）
- 液态玻璃的语言菜单不那么透明了（浅色、深色都是），背后的内容不再透进来影响阅读。

## 0.5.2（2026-10-08）
- 收起成气泡时，鼠标停在气泡上也能看到这次打开魔镜以来发送、接收了多少 token。

## 0.5.1（2026-10-08）
- 液态玻璃加上边缘折射：标签、语言菜单和气泡的边缘会把背后的内容拉伸、弯折（像弧形的厚玻璃），边上还有一丝色散；着色更通透，文字加了光晕，压在复杂背景上也看得清。滚动时不影响流畅度。

## 0.5.0（2026-10-08）
- 收起成气泡：点标签上的“–”，镜框平滑地缩成圆形气泡贴到页面边缘；拖到左边或右边松手会自动吸附，停一会儿藏进边缘一半，鼠标移上去滑出来；点一下气泡，镜框平滑地弹回原处。收起时暂停翻译。
- 可以换皮肤：经典（和桌面版一样）或液态玻璃（半透明磨砂、圆角、高光，跟着系统的浅色 / 深色）。在设置页“外观”里点选，打开着的魔镜马上换。

## 0.4.2（2026-10-08）
- 镜框顶部栏像网速那样显示这次打开魔镜以来发送（↑）和接收（↓）的 token，鼠标停上去看具体数字；服务不报告用量时按字数估算，前面加“≈”。

## 0.4.1（2026-10-08）
- 修正：画布上面压着网页文字的页面（比如 Comfy Cloud 的节点、Markdown 说明节点，图表的图例），镜子里看不到译文。现在这些文字的译文会露出来；画布本身、输入框和文本框照旧显示真网页。

## 0.4.0（2026-10-07）
- 备用阵列：翻译服务可以排好几个（比如 Ollama 云端 → 本机 Ollama → DeepSeek）。前一个出错（额度用完、Key 不对、模型下线、连不上、太慢）就自动换下一个，已经译好的段落不重翻；出错的先跳过一会儿再回头试，点“保存”就重新从主力试起。
- 用上备用时，镜框标签上显示“备用② 模型名”，鼠标停上去能看到主力为什么不能用；设置页的列表里也显示哪个暂时跳过、为什么；“测试全部”一次试完每一个。
- 设置页最下面加了“关于”：意见反馈邮箱；“打赏作者”折叠在里面，完全自愿，不解锁任何功能。
- 扩展名字改成“桌面魔镜 · 网页原位翻译”；镜框标签上的按钮不再被挤窄，字放不下时只省略状态文字。

## 0.3.1（2026-10-07）
- 选“Ollama 云端模型”时，自动试出你的账号现在能用的模型（订阅到期后多数要付费额度，有的已下线）；翻译出错时说清楚是“要付费额度 / 订阅到期”还是“模型已下线”。

## 0.3.0（2026-10-07）
- 翻译服务商补全：本机（Ollama、LM Studio）、订阅套餐（Ollama 云端、智谱 GLM / Kimi Code / 阿里云百炼 / 火山方舟 / MiniMax 的编程套餐）、国内按量付费（DeepSeek、通义千问、智谱、Kimi、MiniMax、豆包、硅基流动、混元、千帆、阶跃、魔搭）、国际（OpenAI、Gemini、Claude、OpenRouter、Groq、Mistral、Grok）。选了自动填地址，拉到模型后自动挑一个轻量的；每家的 Key 分开记。
- 各家关掉“思考”的参数自动带上；服务不认附加参数时自动改用最基本的请求。
- 修正：有些网站用脚本插入的样式，复制时会丢掉部分内边距等设置（浏览器读规则的缺陷），镜子里内容会整体错开几十像素（Vimeo 等）。现在按真网页算好的值补回去。

## 0.2.1（2026-10-07）
- 修正：页面整体在一个可滚动的容器里（侧边栏也在里面）时，滚动后镜子里的侧边栏会跟着正文跑（Tavily 后台等）。

## 0.2.0（2026-10-07）
- 设置里可以“拉取模型”：填好 Key 后自动列出服务上能用的模型，点一下就选上；DeepSeek 默认模型改成 deepseek-flash。
- 先选“母语”：第一次按浏览器语言自动选好，译文默认译成母语；界面跟着母语（中文母语用中文界面，其他用英文界面）。
- 翻译方向：设置里选原文和译成的语言；镜框标签上的语言按钮也能随时切换，选了马上按新方向重翻。指定原文后只翻这种文字。
- 设置里有“版本与更新”：扩展文件夹里有新版本时，一键更新；更新后自动打开设置页说明改了什么。
- 连不上翻译服务时，提示说清楚是哪里连不上。

## 0.1.0（2026-10-07）
- 第一个原型：网页实时复制成“下面那张纸”，译文排进去、每段锁成原文的大小，镜框只露出这一块；滚动时镜内镜外逐帧对齐。
